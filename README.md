📘 Machine Learning Assignment

Supervised Learning & Ensemble Techniques

---

📌 Overview

This project demonstrates the complete machine learning workflow, including:

Data preprocessing

Training supervised learning models

Applying ensemble learning

Performance evaluation and analysis


The goal is to compare different models and analyze how ensemble methods perform on noisy data.


---

🗂️ Project Structure

ml_assignment.ipynb   # Main Jupyter Notebook
README.md             # Project documentation


---

⚙️ Steps Performed

1️⃣ Data Preprocessing

Handled missing and noisy data

Applied normalization / standardization

Performed feature selection (if required)



---

2️⃣ Model Development

The following supervised learning models were trained:

Decision Tree Classifier

Naïve Bayes Classifier


An Ensemble Learning technique was also applied to improve performance.


---

3️⃣ Ensemble Learning

Combined multiple models to improve accuracy

Compared individual models vs ensemble

Analyzed behavior on noisy datasets



---

4️⃣ Performance Analysis

The models were evaluated using:

Accuracy

Precision

Recall

F1-score


Additional analysis:

Confusion Matrix visualization

Overfitting explanation

Use of pruning / regularization to reduce overfitting



---

📊 Results Summary

Decision Tree Classifier performed better than Naïve Bayes on this dataset

Ensemble techniques provided improved accuracy, especially with noisy data

Ensemble learning proved more robust and reliable
